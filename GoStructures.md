# Структуры в Go

Возможно ли сравнить объекты одинакового типа структуры содержащее поле типа слайса `int`?\
\
Как сравнить объекты одинакового типа структуры содержащей не `comparable` поля? Может ли пакет `reflect` помочь в этом?\
\
В чем отличие ресивера по значению от ресивера по ссылке в методах?\
\
Как обновить значения полей объекта в одной строкой?

<details open>
  <summary><h3>Что выведет код?</h3></summary>

```go
type A struct {  // какой физический и фактический размеры структуры?
	a bool
	b int32 
	c float64
}

type B struct {  // сумма размеров полей равна фактическому размеру структуры?
	c float64
	b int32
	a bool
}

type C struct {  // как эффективно организовать поля чтобы уменьшить фактический размер структур в памяти?
	a bool
	c float64
	b int32
}

func main() {
	println(unsafe.Sizeof(A{}))
	println(unsafe.Sizeof(B{}))
	println(unsafe.Sizeof(C{}))
}
```
